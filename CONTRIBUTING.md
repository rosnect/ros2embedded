# Contributing

Bug reports, documentation fixes, examples, and code contributions are welcome.
This is a tinkering project maintained as time allows; responses and releases
have no guaranteed schedule.

## Reporting issues

Include your ROS distribution, operating system, transport (MQTT or serial),
device model if relevant, and steps to reproduce the problem. Include the
expected and actual behavior and relevant logs. Remove credentials, private
keys, and other sensitive information from logs and configurations before posting.

## Proposing changes

For larger changes, open an issue to discuss the approach first. Keep pull
requests focused, explain the problem and resulting behavior, and describe how
you checked the change. Update documentation and examples when behavior changes.

Follow the build and test instructions in [README.md](README.md#tests). Run the
checks relevant to your change, and report any checks you could not run,
including hardware or Flutter/Rosnect testing. Do not claim on-device testing
based only on host-side tests.
